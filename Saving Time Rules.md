**Key Rules to Avoid Falling Behind:**
-
*Never debug alone for more than 15 minutes:* If a GCP command or permission fails, log it immediately in TROUBLESHOOTING Log.md & share exact error text.
*Hardcode fallbacks:* If an external API key takes too long to get approved, use static mock JSON file for that specific source so coding isn't blocked.
*Use standard templates:* Reuse the Secret Manager and Cloud Run deployment scripts established in prior planning to avoid writing commands from scratch.
